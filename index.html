  • 01 MotivAI ~60%inference cost cut AI Agent Platform 2026

    A goal-based social platform where people post daily progress and an autonomous AI agent reacts to it — production-deployed end to end.

    PROBLEM
    Habit apps die when nobody responds to your progress. Generating a genuine, personalized reaction for every post with a frontier model is far too expensive to run at scale, and naive LLM output is unreliable enough to break the product.
    BUILT
    A 3-node LangGraph agent (retrieve → generate → store) with Pydantic v2 structured outputs. Added intelligent model routing — GPT-4o for milestone streaks, GPT-4o-mini for routine posts — plus a pgvector semantic cache to kill redundant calls, a 2-layer guardrail system (regex pre-filter, then an embedding cosine classifier), and Langfuse tracing on all three nodes. Real-time group chat runs on Redis Streams consumer groups with SET NX idempotency for exactly-once processing.
    IMPACT
    ~60% lower inference cost while holding a 0.834 RAGAS answer-relevancy score on a 25-entry golden dataset. Live in production across Render, Railway, Neon, Upstash and Vercel with GitHub Actions CI.

  • 08 Audit & Analyse AI Agents 2026

    A two-agent research pipeline: an analyst that answers questions with cited web research, and an independent auditor that checks every claim against the page it cites.

    PROBLEM
    Research agents give confident answers with citations that often don’t actually support the claim. Trusting them means verifying each claim independently, without the cost of the pipeline becoming unpredictable.
    BUILT
    An analyst that plans, runs web retrieval in parallel, ranks evidence with embeddings and synthesizes cited claims, with a SQLite fact-graph memory that carries entities across questions. Fixed three real bugs the live run exposed (cost accounting, embedding batch limits, chunk splitting).

  • 03 minigraph ~150lines · 0 deps Agent Framework 2026

    A minimal LangGraph-style agent framework rebuilt from scratch in ~150 lines of pure Python, zero dependencies.

    PROBLEM
    I was running LangGraph in production for MotivAI but couldn’t confidently explain what happens when a node crashes mid-run, how state reducers merge under the hood, or what checkpointing actually persists. Debugging a black box you depend on is a liability.
    BUILT
    The core execution engine from first principles: nodes and directed edges, shared state with per-key custom reducers, conditional routing, cycles with a max-iteration guard, streaming that yields state after each node, and checkpointing that saves state plus the next node to disk so a crashed run resumes without re-executing completed nodes.
    IMPACT
    Validated by rebuilding MotivAI’s entire 3-node production pipeline on top of it with identical behavior. 7-test suite covers every feature, including a crash-and-resume test proving completed nodes don’t re-run.

  • 09 Ask the Data NL-to-SQL · AI Engineering 2026

    A natural-language-to-SQL system that lets stakeholders ask questions about a database in plain English, with the generated SQL validated and run read-only.

    PROBLEM
    Business users can’t write SQL, and the database uses cryptic names (table1.field10) that an LLM can’t interpret. Letting a model write queries directly against live data also risks wrong answers and unsafe statements.
    BUILT
    A catalog that turns schema comments into readable names (companies.status), so the LLM only ever sees meaningful names and real data values. Hybrid retrieval picks the relevant tables, combining HNSW embeddings with SQLite FTS5/BM25 via Reciprocal Rank Fusion. A foreign-key join graph with BFS shortest paths supplies exact join conditions. A sqlglot validator, with no LLM involved, enforces single read-only queries, checks that every table, column and value exists, and translates names back to the physical schema. Queries run read-only (SELECT-only user, read-only transaction, 5-second timeout) with a bounded retry loop that feeds fixable errors back to the model. Served through a CLI and a FastAPI web page, on SQLite or MySQL.
    IMPACT
    Plain-English questions become safe, explainable SQL, with the query, assumptions and warnings shown next to the result. The validation and retry layers are covered by 18 offline tests that need no API key.
    PythonFastAPIsqlglotHNSWSQLite FTS5MySQLOpenAI / Anthropic APIs
